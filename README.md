# Desenvolvimento de Plataformas Móveis (Unifor)

Projetos em React Native com Expo desenvolvidos na disciplina de Desenvolvimento de Plataformas Móveis.

| Projeto | O que faz | Destaques |
|---|---|---|
| [`tmdb-busca-filmes`](tmdb-busca-filmes) | Busca filmes na API do The Movie Database | Consumo de API REST, estados de carregamento, erro e lista vazia |
| [`termos-de-uso-firebase`](termos-de-uso-firebase) | Tela de aceite de termos de uso | Persistência local (AsyncStorage) e em nuvem (Firestore) em paralelo |

Cada pasta tem seu próprio README com instruções para executar.
